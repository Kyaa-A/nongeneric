# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
AI-assisted software engineers, design engineers, creative technologists, and autonomous coding agents (Claude Code, OpenAI Codex, Cursor, Antigravity, GitHub Copilot) building production web and application interfaces who refuse to ship generic AI templates.

## Product Purpose
Eliminate statistical-average AI design slop (`Inter` + purple/indigo gradients + `background-clip: text` + 3-column icon-in-circle card grids + layout-thrashing animations + 320px horizontal overflow) by equipping AI coding agents with a deterministic 82-rule static detector, an offline-first Aesthetic World & Concept Seed engine, an OKLCH token compiler, and a production-grade GreenSock (GSAP) motion choreography generator.

## Positioning
The only multi-harness agent skill and CLI engine that unifies opinionated Art Direction & Visitor Mode laws (`pbakaus/impeccable`), 8-domain GreenSock motion mastery (`greensock/gsap-skills`), and 320px–1440px responsive layout hardening (`Kyaa-A/doesntbreak`) with an offline-first Concept Seed catalog and zero-dependency TypeScript detector.

## Operating Context
Runs both inside agent prompt contexts (`skills/nongeneric/SKILL.md`, `commands/*.md`, `agents/*.md`) and as a deterministic CLI verification gate (`npx nongeneric detect`, `seed`, `tokens`, `motion-plan`, `audit`) in local development and GitHub Actions CI.

## Capabilities and Constraints
- Zero runtime npm dependencies (`dependencies: {}`).
- 82 deterministic anti-pattern rules across `slop`, `quality`, `motion`, `responsive`, `copy`, and `security`.
- Offline-first SHA-256 `concept-seed` engine dealing curated Challenger Worlds and Structural Compositions.
- Strict DOM security (`innerHTML` and `eval` banned).

## Product Principles
1. **Commit to a World, Never a Template**: Every surface commits to a named Aesthetic World and serves its Visitor Mode (`persuade`, `operate`, `read`, `experience`).
2. **Working Proof in the First Viewport**: Persuade surfaces demonstrate a live interactive mechanism in the hero (inspired by `KnightVision`), never decorative filler.
3. **60fps Compositor Choreography**: Motion is authored on `transform` and `autoAlpha` via GSAP with mandatory `gsap.matchMedia()` reduced-motion parity and `useGSAP` / `gsap.context()` cleanup.
4. **Deterministic Verification Over Self-Praise**: No surface is complete until `nongeneric detect` exits `0` with `0` primary anti-patterns.
