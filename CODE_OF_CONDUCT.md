# Code of Conduct

We pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

## Expected Behavior

- Discuss ideas and code respectfully, and make criticism specific and actionable.
- Welcome newcomers and respect different levels of experience.
- Accept constructive feedback and take responsibility for mistakes.
- Respect privacy and keep discussion relevant to the project.

## Unacceptable Behavior

Harassment, threats, discriminatory remarks, sexualized conduct, personal attacks, deliberate disruption, and publishing another person's private information without permission are not acceptable.

## Scope and Enforcement

These expectations apply to repository issues, pull requests, code reviews, and other project-managed spaces. The maintainer, [Asnari Pacalna (Kyaa-A)](https://github.com/Kyaa-A), may edit or remove content and warn, restrict, or block participants based on the severity and repetition of a violation.

Report problematic GitHub content using GitHub's reporting tools. For a project moderation concern without sensitive details, open an issue requesting maintainer attention and link the relevant public interaction. Do not post private information in an issue; use GitHub's private reporting tools for abuse involving sensitive information.

Moderation should be proportionate, consider context, and explain the action where doing so does not compromise privacy or safety.
