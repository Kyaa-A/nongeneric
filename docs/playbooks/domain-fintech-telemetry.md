# Domain Playbook: Fintech Telemetry

Authoritative design playbook for trading terminals, institutional ledgers, and real-time observability dashboards.

## Core Rules

1. **Ban Decorative Metrics:** Banning decorative 4-card KPI rows with fake +12.5% badges. These are "slop" and not acceptable.
2. **Numeric Alignment:** Enforcing right-aligned cells with `tabular-nums` for all financial tables and data grids.
3. **Grid Borders:** Use hairline grid borders exclusively for definition and structure.
4. **Direct Entry:** Direct-to-workspace entry is required. No superfluous landing pages before the data workspace.
